Tienda en línea (demo). Pregúntale al asistente sobre envíos, devoluciones, pagos o el estado de tu pedido — el botón de chat está abajo a la derecha.

¿Qué es esto?

Un widget de chat embebible con RAG 100% local (Ollama + Chroma): consume la misma API (/chat) que usa el bot de Telegram de este proyecto. Para ponerlo en tu propio sitio solo necesitas este snippet: 

<script>
  window.RAG_WIDGET_CONFIG = { apiBaseUrl: "http://localhost:8000" };
</script>
<script src="widget.js"></script>

Sin build step, sin dependencias — widget.js inyecta su propio CSS y arma el panel de chat al cargar.
